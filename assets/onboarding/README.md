# Картинки онбординг-теста

Положи сюда три файла ЭКГ для вступительного теста (порядок важен):

| Файл       | Что на ЭКГ                                  | Правильный ответ |
|------------|---------------------------------------------|------------------|
| `ecg1.jpg` | 9-летняя девочка, сердечный шум             | Норма            |
| `ecg2.jpg` | 37-летний мужчина перед операцией           | Норма            |
| `ecg3.jpg` | 25-летний профессиональный футболист        | Норма            |

Если файла нет — бот отправит вопрос текстом без картинки и запишет
предупреждение в лог. Имена файлов и тексты задаются в
[`services/content.py`](../../services/content.py).
